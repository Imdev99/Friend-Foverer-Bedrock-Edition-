## 🇺🇸 English Description

### Introduction
"Friends Forever" is a heart-touching Bedrock Edition port of the original Java mod by **ConRad**. This mod honors the unbreakable bond between players and their loyal companions. Even after death, your dog's soul remains to protect you until you're ready to say a final goodbye with the sacred **Soul Glass**.

### Features
* **Eternal Loyalty:** Tamed wolves return as ghosts after death.
* **Soul Glass System:** Specialized item used to "Open the Eyes" and reveal the spirits.
* **Heavenly Farewell:** Cinematic goodbye scene with custom particles and heart-wrenching dialogue.
* **Performance Optimized:** Normal Experience if you don't add shader.

### Technical Specifications
* **Namespace:** `friends_forever`
* **Format:** `.mcaddon` (Behavior Pack + Resource Pack)
* **Required Version:** 1.20.10 or higher.

## 🇹🇭 คำอธิบายภาษาไทย (Thai Description)

### บทนำ
"Friends Forever" คือโปรเจกต์พอร์ตมอดจากเวอร์ชัน Java (ต้นฉบับโดย **ConRad**) มาสู่ Bedrock Edition รังสรรค์โดย **imdev99** เพื่อเชิดชูมิตรภาพที่ไม่มีวันตายของสุนัขผู้ภักดี แม้ร่างกายจะดับสูญ แต่วิญญาณจะยังคงปกป้องและรอคอยคำบอกลาครั้งสุดท้ายผ่านการส่องกระจก **Soul Glass**

### คุณสมบัติเด่น
* **วิญญาณผู้ภักดี:** สุนัขที่เชื่องแล้วจะกลับมาในร่างวิญญาณหลังจากตาย
* **ระบบเปิดเนตร:** ต้องใช้ไอเทม Soul Glass เพื่อมองเห็นวิญญาณ (หากไม่ถือจะมองไม่เห็น)
* **ลำแสงแห่งสวรรค์:** ฉากส่งวิญญาณสุดซึ้ง พร้อมเอฟเฟกต์แสงและบทสนทนาที่บีบคั้นน้ำตา
* **รองรับภาษาไทยเต็มรูปแบบ:** กวาดล้างปัญหาสระลอย เพื่อพรรษาความกริบในเครื่อง Vivo

## 🛠️ Installation / วิธีติดตั้ง
1. Download the `.mcaddon` file.
2. Open the file to import it into Minecraft Bedrock.
3. Activate both **Behavior Pack** and **Resource Pack** in your world settings.
